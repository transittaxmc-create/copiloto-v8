# Copiloto V8

Parallel rebuild of the driver companion app (does **not** touch Copiloto V7 / claris-lime).

## Features

- **Today** — trip entry, GPS with timeout + manual fallback, shift START/BREAK/END
- **Earnings** — list, gross/net, pending/matched/difference, anti-duplicate on save
- **Money** — bank deposits vs net, simple reconcile
- **Reports** — $/h, daily goal, 7-day chart, platform breakdown
- **More** — export/import JSON, reset, AI placeholder

## Local dev

```bash
npm install
npm run dev
```
